# Vyuham engineering logbook

A dated, human-readable record of significant engineering work on Vyuham. One file per entry:
`YYYY-MM-DD-short-title.md`. Each entry states what changed, why, the evidence (commits, tests,
documents) and anything left pending. Entries are added, never rewritten; corrections are new
entries that reference the earlier one.

Once the Vyuham Engineering Control Center (VECC) is running, it becomes the authoritative,
machine-collected history. This logbook stays the narrative record, and VECC's own installation and
changes are always logged here.
